Étapes mise en production sur Netlify :
-> prérequis : avoir un compte Netlify

1) Dans ton projet web, installe le Netlify CLI
$ npm install -g netlify-cli

2) Ouvre un bash dans ton dossier de projet (dans \front)

3) Initialise la création de ton nouveau site vers Netlify (suivre les étapes de configs proposées)
$ ntl init

3) Déploie le site en production
$ ntl deploy --prod

4) Le lien du site est détaillé à la fin de la mise en prod.
